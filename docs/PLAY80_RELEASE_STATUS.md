# PLAY80 প্রকাশের কাজের হিসাব

**বর্তমান অবস্থা।** মালিক পাসওয়ার্ড বদলানোর কথা নিশ্চিত করেছেন। তাঁর অনুমতিতে play80_Master_signing_key_ENCRYPTED.bin ও PLAY80_Release_Backup.p12 দুটিই ট্র্যাশে সরানো হয়েছে। নতুন চাবি তৈরির ব্যবস্থা GitHub Actions-এ। নতুন ব্যাকআপ সংরক্ষণ ও যাচাইয়ের আগে প্রকাশ করা যাবে না।

### আগের কাজের রেকর্ড


মালিক PLAY80_SIGNING_PASSWORD বদলানোর কথা নিশ্চিত করেছেন। আগের প্রকাশিত পাসওয়ার্ড ব্যবহার করা যাবে না। নতুন চাবি তৈরির আগে পুরোনো ব্যাকআপ মোছার সুনির্দিষ্ট তালিকায় মালিকের সিদ্ধান্ত বাকি।

**বর্তমান সিদ্ধান্ত।** মালিক অব্যবহৃত চাবিটি বাদ দিয়ে একবার নতুন চাবি তৈরির অনুমতি দিয়েছেন। আগের চাবি উদ্ধারের অপেক্ষা শেষ। প্রথমে মালিক তাঁর পাসওয়ার্ড ম্যানেজারে নতুন পাসওয়ার্ড সংরক্ষণ করে PLAY80_SIGNING_PASSWORD হিসেবে GitHub Actions-এ রাখবেন। নতুন চাবি এখনও তৈরি হয়নি। পরবর্তী ধাপে এনক্রিপ্টেড ব্যাকআপ আলাদা স্থানে রেখে সেটি দিয়ে চাবি খুলে সার্টিফিকেট মেলাতে হবে। পুরোনো ফাইল মুছতে হলে আগে নির্দিষ্ট তালিকা নিশ্চিত করতে হবে।

পূর্ববর্তী অবস্থার সর্বশেষ আপডেট ২৬ নভেম্বর ২০২৬ (ঢাকা)। পরের কাজ শেষে এই এক নথিতেই ফল ও পরীক্ষার লিংক যোগ করতে হবে।

- মূল অ্যাপ ও কোড এই রিপোজিটরিতে। বর্তমান প্রকাশিত APK পুরোনো V5.2 QA। সেই বিল্ডে অস্থায়ী চাবি ব্যবহার হয়েছিল।
- সাইন ইন, সাইন আপ, Owner থেকে DSR তৈরি, PIN রিসেট ও প্রকাশের সংশোধন main-এ যুক্ত। GitHub ব্রাউজার পরীক্ষা সফল। বাস্তব DSR তৈরি ও ইমেইল পৌঁছানো পরীক্ষা বাকি।
- নতুন স্থায়ী চাবি একবার তৈরি হয়েছে। তার পাসওয়ার্ড-সুরক্ষিত ব্যাকআপ PLAY80_Release_Backup.p12। সার্টিফিকেটের প্রকাশ্য পরিচয় main-এর release-qa.yml-এ আছে। এই চাবি দিয়ে এখনও APK প্রকাশ হয়নি।
- পুরোনো play80_Master_signing_key_ENCRYPTED.bin ভিন্ন ব্যাকআপ। তার পাসফ্রেজ অনুপলব্ধ। দুটি ফাইল গুলিয়ে ফেলা যাবে না।
- মালিক GitHub Device Login অনুমোদন করেছেন। নতুন চাবির পাসওয়ার্ড যে সেশনে তৈরি হয়েছিল সেটি বর্তমানে অনুপলব্ধ। Device Login কোড দিয়ে ব্যাকআপ খোলা যায় না।
- পরবর্তী কাজ আগের সেশন থেকে বিদ্যমান চাবি পুনরুদ্ধার, মালিকের কাছে আলাদা নিরাপদ জায়গায় পাসওয়ার্ড সংরক্ষণ ও ব্যাকআপ খুলে যাচাই। এরপর GitHub Actions Secrets সেট, GitHub বিল্ড, Android 14-এ পরিষ্কার ইনস্টল ও একই নতুন চাবির সংস্করণের ওপর আপডেট পরীক্ষা এবং অনুমোদিত প্রকাশ। পুরোনো অস্থায়ী চাবির V5.2 থেকে একবার পরিষ্কার ইনস্টল লাগবে।
- মালিক একটি অ্যাপ ও একটি স্থায়ী চাবি চান। সেশন হারালে নিজের সিদ্ধান্তে নতুন চাবি বানানো যাবে না। বদলানোর প্রয়োজন হলে আগে পুরোনো উপকরণের সঠিক তালিকা ও প্রভাব জানিয়ে কোনগুলো মুছতে হবে তার স্পষ্ট অনুমোদন নিতে হবে। বিদ্যমান APK, কোড বা ব্যবহারকারীর ডেটা মুছে ফেলার অনুমতি নেই।
- মালিককে কী সংরক্ষণ করতে হবে তা সময়মতো জানাতে হবে। পাসওয়ার্ড বা ব্যক্তিগত চাবি চ্যাট, এই নথি, কোড বা লগে লেখা যাবে না।
