## Approved presentation rules

- Premium, cohesive purple/gold PLAY80 identity; retain each game's distinctive icon.
- Chess: black-and-white 8×8 square board, responsive square cells, premium 3D chess pieces.
- Game flow: select game → scrollable, game-specific rules/information → **OK, PLAY** → gameplay.
- Keep ordinary policy/explanation popups outside gameplay; technical errors, consent, authorization and essential game state remain allowed.
- Actual game mechanics and policy text are controlled by the owner's explicit instructions and will be revised when approved; avoid inventing policies.
- Brand/design files should be backed up in Google Drive; development source and APK Releases belong in GitHub.
- Do not change these **approved visual designs** without the owner's later instruction. Bug fixes and accessibility/responsiveness improvements must preserve this identity.
